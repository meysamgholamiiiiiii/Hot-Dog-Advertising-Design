# Hot Dog Advertising Design

![Hot Dog Design](./images/hot-dog-design.png)

## About the Project

A promotional hot dog design created as a graphic design project for food and restaurant advertising.

The design focuses on an attractive food presentation, clear visual hierarchy, typography, composition, and an engaging promotional style.

## Project Overview

This project includes a complete visual design for a hot dog food product, prepared for promotional and advertising purposes.

The project contains the final design, visual elements, and a PDF version of the artwork.

## Design Features

* Food advertising design
* Product-focused visual composition
* Clear typography and hierarchy
* Attractive visual presentation
* Balanced layout and spacing
* Promotional design approach
* Suitable for digital and print presentation
