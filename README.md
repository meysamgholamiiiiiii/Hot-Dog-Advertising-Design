# Hot Dog Advertising Design

A promotional food advertising design created with Adobe Illustrator for a hot dog product.

## About the Project

This project is a promotional graphic design created for food and restaurant advertising.

The main goal was to create an attractive and visually engaging presentation for a hot dog product, with a strong focus on food presentation, typography, composition, visual hierarchy, and commercial appeal.

## Project Overview

The project includes a complete promotional design for a hot dog product, prepared for both digital and print presentation.

The design combines product-focused visual elements with typography and layout to create a clear and appealing advertising composition.

## Design Features

* Food advertising design
* Hot dog product presentation
* Strong visual hierarchy
* Professional typography
* Balanced composition
* Clear layout and spacing
* Promotional visual style
* Product-focused design
* Suitable for digital and print use
